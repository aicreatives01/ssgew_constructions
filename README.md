# Shree Sai Genesh Engineering Works Website

This is a simple static website for the construction company specializing in residential and small commercial houses.

## Usage

Open `index.html` in your web browser to view the website.

## Structure

- `index.html`: Main homepage with sections for home, services, about, and contact.
- `css/style.css`: Stylesheet for basic styling.
- `js/`: Directory for JavaScript files (currently empty).
- `images/`: Directory for images (currently empty; add company logo or project photos here).

## Customization

- Update contact information in `index.html`.
- Add images to the `images/` folder and reference them in the HTML.
- Modify styles in `css/style.css` for branding.

## Troubleshooting

- If the page doesn't load, ensure all files are in the same directory structure.
- For advanced features, consider adding JavaScript or a framework like Bootstrap.
